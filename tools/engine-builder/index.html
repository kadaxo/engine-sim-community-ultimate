Engine builder

Make your own engine for Engine Simulator by filling in plain values: cylinders, bore and stroke, cams, intake, exhaust, ignition, the car it sits in and its gearbox. The builder writes the engine file for you.

How it works

  1. Pick a preset to start from and press "Use this preset", or keep the one that is filled in.
  2. Change any values you like. Each field says what it does and which values are allowed.
  3. Press "Save engine file". The file goes to your Downloads folder.
  4. In the simulator, press O. With speech on, the engine list has it under its name followed by "in Downloads"; without speech, open the file in the Open dialog. After saving a changed version, load it again the same way.
  5. To change an engine later, use "Open an engine made with this builder" below; all of its values come back into the form.

Start from a preset
