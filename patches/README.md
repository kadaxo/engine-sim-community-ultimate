# Submodule patches

The submodules are pinned to commits that live in community forks (see
`.gitmodules`). A few fixes on top of those commits aren't published in any
fork yet, so they're kept here and CMake applies them to the submodule working
tree when you configure the project (`dependencies/submodules/CMakeLists.txt`).
Patches already in the working tree are detected (the newest one that can be reversed marks how far an earlier configure got) and skipped, so re-running CMake is safe.

After configuring, `git status` reports the patched submodule as having
modified content. That's expected; `git -C <submodule> checkout .` undoes it
and the next configure re-applies the patches.

## delta-studio

Pinned commit: `8daecd0` on
[0xsuk/engine-sim-linux-can-delta-studio](https://github.com/0xsuk/engine-sim-linux-can-delta-studio)
(bobsayshilol's SDL port plus a larger SDL audio callback buffer).

| Patch | What it fixes |
| --- | --- |
| `0001` | MSVC build of `physics/src/collision_detector.cpp` (Windows `min`/`max` macros), by David ([Creesic/delta-studio](https://github.com/Creesic/delta-studio) `macos-port`) |
| `0002` | Direct3D 10/11 input layouts after the `std::string` conversion (`SemanticName`) |
| `0003` | `ysWindowsMonitor` calling the removed `InitializeDeviceName()` |
| `0004` | Release builds importing the debug-only `d3dx10d_43.dll`, by Danniel-Porto ([Danniel-Porto/delta-studio](https://github.com/Danniel-Porto/delta-studio) `release-directx-linking`) |
| `0005` | `ysSubclassRegistry` writing one pointer past the device table when the Vulkan device registers (global memory corruption on Windows at startup) |
| `0006` | `FindSDL2` not exporting the directory above `SDL2/`, so `<SDL2/SDL.h>` couldn't be found with vcpkg or the SDL development packages |
| `0007` | `ysWindowsWindow` no longer overriding the `std::string` window methods, so no Win32 window was created and the app crashed at startup on Windows |
| `0008` | The SDL key map missing the period key (the brake key) on Linux and macOS |
| `0009` | Keyboard and mouse input injected by software (on-screen keyboards, voice control, screen readers passing keys through, key remappers) being dropped on Windows because it has no device handle |
| `0010` | The SDL key map missing F1–F12, Page Up/Down, Home, End, Insert, 0, [ and ] on Linux and macOS (the screen reader readouts, the mouse-wheel keys, the spoken engine list, switching engines, slow motion and view rotation) |
| `0011` | Builds with current compilers: headers using the fixed-width integer types include `<cstdint>` (GCC no longer pulls it in indirectly), the OpenGL device includes `<cassert>`, the macOS OpenGL headers path is set on `delta-core` instead of a misspelled target, `delta-physics` gets the `sse2neon` include directory it needs on Apple Silicon, and `delta-basic` links its libraries whole with `-force_load` on macOS instead of GNU ld's `--whole-archive` |
| `0012` | `ysToolAnimationFile` returning an uninitialized error code for animation file versions other than 0, by kyan0s-git ([kyan0s-git/engine-sim](https://github.com/kyan0s-git/engine-sim)) |
| `0013` | The GLSL shaders needing OpenGL 4.2 for their `layout(binding = N)` qualifiers while macOS only provides 4.1, so the app crashed on start: shaders are rewritten to GLSL 4.10 when loaded and their bindings set after linking, uniform blocks use `std140`, and the SDL context asks for a forward-compatible core profile with a 4.1 fallback, by kyan0s-git ([kyan0s-git/engine-sim](https://github.com/kyan0s-git/engine-sim)) |
| `0014` | Error messages (such as a shader compiler log) not reaching error handlers, which only got the error number |
| `0015` | SDL windows larger than the screen being cut off on macOS, which doesn't shrink them: the window is fitted into the display's usable area and the size it really gets is recorded so the render targets match |
Without 0001–0007 the port only builds on Linux/macOS; with them it builds on
Windows (Direct3D 11) as well.

## Moving a patch into a fork

If you host your own fork of a submodule, you can turn its patches into
commits and drop its patch directory, for example for delta-studio:

```sh
cd dependencies/submodules/delta-studio
git checkout -b engine-sim-community 8daecd0
git am ../../../patches/delta-studio/*.patch
git push <your-fork> engine-sim-community
```

Then point `.gitmodules` at the fork, commit the new submodule pointer and
delete `patches/delta-studio`.
