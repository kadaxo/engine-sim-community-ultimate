Engine Simulator accessibility guide

This guide is for people who use Engine Simulator with a screen reader. The simulator speaks through your own screen reader, so you hear it with your usual voice and settings, and anything it says also appears on a braille display.

Getting started

  • Speech starts by itself when a screen reader is running: NVDA, JAWS, Narrator, ZoomText, System Access and several others are supported.
  • Without a screen reader, press J once and the Windows voice is used instead.
  • This guide describes Windows. On Linux or a Mac, also read Linux and macOS.
  • When the simulator opens it says the name of the engine it loaded, for example "Loaded Subaru EJ25".
  • The simulator window has no buttons or menus to move through. Everything is done with single keys, listed below, and the simulator answers out loud.
  • To start an engine: press A to turn the ignition on, then hold S for the starter until you hear "Engine running".

Choosing an engine

Press O to open the engine list. You hear how many engines there are, then the engine that is running now. The engine keeps running while you browse, and the driving keys are off until the list closes.

  • Engines are read by the name in their file, for example "Honda B18C5, VTEC, I4", in alphabetical order with their place in the list.
  • When two engines have the same name, the file name follows it so you can tell them apart, for example "Subaru EJ25, file 02 subaru ej25 uh".
  • Engines you saved from the engine builder into your Downloads folder are in the list too, followed by "in Downloads".
  • The last entry, "Another file", opens the Windows Open dialog for an engine file anywhere else.

Without speech, O opens the Windows Open dialog as before.

[ and ], the two keys to the right of P, load the previous or next engine straight away, in the same order as the list, with or without speech. You hear "Loaded", the engine's name as the list reads it and its place, for example "Loaded Honda B18C5, VTEC, I4, 39 of 102". Like an engine chosen from the list, it starts switched off.

What is announced on its own

  • Ignition, starter, dyno, hold, smart shifting and leveler switching on or off
  • Gear changes, neutral and the clutch going down
  • "Engine running" once the engine catches, and "Engine stalled" or "Engine stopped"
  • The new value after you adjust volume, dyno hold speed or another setting
  • About a second after you change the simulation frequency: how hard the computer is working at the new setting
  • "Loaded" and the engine name after opening or reloading an engine
  • When an engine file has a mistake: the file, the line number and what is wrong. The engine that was running keeps running.
  • When a dyno run reaches redline: peak power and peak torque with their rpm

Dyno runs and reports

Press A and hold S to start the engine, stay in neutral, press D and hold R. The dyno raises the engine speed until redline and then switches itself off. You hear the peak power and torque, and a report is saved as a spreadsheet file (CSV) named after the engine and the time, for example dyno_Subaru_EJ25_20261111-142233.csv. It has one row every 50 rpm with torque and power, and opens in Excel or any text editor. It is saved in the simulator's output folder, which is the folder that holds engine-sim-app.exe unless you have changed it.

Building your own engine

The engine builder is a web page with an ordinary form: pick a layout (single, parallel twins with a 360, 180 or 270 degree crank, boxer twin, 45 and 90 degree V-twins, inline 3 to 6, crossplane inline 4, flat 4 and 6, V4, V6 even or odd firing, V8 cross-plane with four firing orders or flat-plane, V10 even or odd firing, V12, and 7, 9 and 18 cylinder radials), then fill in bore, stroke, compression, cam timing, intake, exhaust, ignition timing, the vehicle and the gearbox. With diesel fuel, a diesel section sets its idle speed, its injection system and how loud its clatter is. Every field says what it does and which values are allowed. Start from one of the presets, change what you like and press "Save engine file". The file goes to your Downloads folder. In the simulator, press O: it is in the engine list under its name, followed by "in Downloads".

To change an engine you made, open it in the builder with "Open an engine made with this builder": all of its values come back into the form. The builder is in the tools\engine-builder folder as index.html, F2 in the simulator opens it, and it works in any web browser, without an internet connection.

Changing an engine

Every engine is a plain text file ending in .mr in the assets\engines folder. They can be read and edited in Notepad or any other text editor.

  1. Make a copy of the engine file you want to change, so the original stays as it was.
  2. Open the copy in a text editor. Many community engines keep their main settings near the top, one per line, each with a comment saying what it does, for example label E_B(170.0) // Cylinder bore diameter. Units: millimeters.
  3. Change a value and save the file.
  4. In the simulator, press O and choose the copy from the engine list, or press Enter if it is already loaded. While the copy has the same name as the original, the list adds the file name to tell them apart; change its name: line to give it a name of its own.
  5. If you hear "Script error", the message gives the file name, the line number and the problem. Fix it, save and press Enter again. The full list of errors is in error_log.log in the output folder.

The exhaust sound is shaped by the exhaust settings (pipe lengths and diameters) and by the impulse response, a recording that gives the exhaust its character. In an engine file the impulse response is chosen on the line that contains impulse_response, for example ir_lib.mild_exhaust_0 or one of ir_lib.smooth_01 to ir_lib.smooth_49.

If the sound stutters

The simulator works out the engine thousands of times a second. This is the simulation frequency, its frame rate. Most engines start at 10000 hertz. A higher frequency sounds cleaner at high rpm, but if the computer can't keep up, the sound crackles or breaks up.

  1. Hold N and press Page Down to lower the frequency by 200 hertz, or hold Page Down to keep lowering it. Page Up raises it. Hold Space as well for steps of 20 hertz.
  2. When you let go, you hear the new frequency. About a second later you hear the load: how much of the available time the simulation uses. Below 80 percent is comfortable. At 80 percent or more you hear "close to the limit", and above 100 percent "too high for this computer".
  3. Press F12 at any time to hear the frequency, the load and the frames per second.

The frequency goes back to the engine's own setting when you load or reload an engine. To keep a different one, change the simulation_frequency line in the engine file.

What the simulator does not model

Oil pressure, oil temperature and coolant temperature are not simulated, so there is nothing to read for them. The sound is the exhaust, plus the whistle, whine and blow-off of an engine with a turbocharger or supercharger, and a diesel's knock and injector ticks: intake roar, gear whine, tyres and wind are not part of it.

If nothing is spoken

  1. Make sure the simulator window has focus: press Alt + Tab to it, then press F5.
  2. Press J. If you then hear the Windows voice but not your screen reader, the screen reader was not recognized.
  3. To help find the problem, start the simulator from a Command Prompt with a speech log: 
    set ENGINE_SIM_SPEECH_LOG=%USERPROFILE%\Desktop\engine-sim-speech.txt
engine-sim-app.exe
    The first line of the log says which screen reader was found, and every announcement is written below it. Please send that file along with your report.

Linux and macOS

Screen reader support on Linux and macOS is written but not yet tested: so far it has only been tried on Windows. If you try it, please report what works and what doesn't, with a speech log (see below).

  • Speech goes to Orca on Linux and to VoiceOver on macOS when they are running. After J, the Speech Dispatcher voice on Linux or the macOS system voice is used instead.
  • The keys are the same as on Windows. The engine list's last entry is "Another file, with the file dialog".
  • Orca's desktop layout uses Insert as its own key, like NVDA and JAWS, so Insert (video recording) probably won't reach the simulator.
  • VoiceOver's own commands use Control + Option. The simulator doesn't use those keys, so they don't clash.

On a Mac keyboard:

  • The top row controls brightness and volume unless you hold Fn. To use F1 to F12 without Fn, turn on "Use F1, F2, etc. keys as standard function keys" in System Settings, Keyboard.
  • F11 shows the desktop in macOS. To use it for the engine information readout, turn off the "Show Desktop" shortcut in System Settings, Keyboard, Keyboard Shortcuts, Mission Control.
  • Mac laptops have no Page Up, Page Down, Home or End keys: use Fn + Up Arrow and Fn + Down Arrow for Page Up and Page Down, and Fn + Left Arrow and Fn + Right Arrow for Home and End.

To write a speech log, start the simulator from a terminal in its build folder:

ENGINE_SIM_SPEECH_LOG=~/engine-sim-speech.txt ./engine-sim-app
